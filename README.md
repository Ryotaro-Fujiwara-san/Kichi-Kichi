# Kichi-Kichi



## 開発目標（MVP） / Development goals (MVP)

熟練者の作業をカメラで撮って音声で説明するだけで、翌日には現場でどんな形状・構造ロボットでも動くノーコード立ち上げエンジン（人間による微修正UI付き）の開発を目標にします。
実際にこの学習エンジンで見よう見まねで動くロボットに対して、自然言語とカメラにより時折ユーザーが動作にダメ出ししたり修正を加える微修正UIにより、特別な機器やプログラミング知識を用いずにファインチューニングをできるようにします。
また、初めて扱う未知の物体に対しても、ロボットは自律的に学習して対応します。触覚センサー付きのハンドを使って物体を回転させながら多角的に形を捉え、さらに力を加えてどれくらい変形するかを観測することで、その物体の硬さを予測します。こうして得られた形状や硬さの情報は、仮想空間（シミュレータ）内に立体データとして再現し、保存します。
データが完成したら、仮想空間で大量のシミュレーション（強化学習）を行い、その物質を自在に扱える知識として保存します。
最終的には、MABEL( https://robotmabel.github.io/website/ )のような安価な機体が特別なファインチューニング作業を通さずに、特定のタスクをこなせることで導入コストを下げ、資金調達を実現します。
